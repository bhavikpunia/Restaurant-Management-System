\# 🍽️ Restaurant Management System



A Java console-based Restaurant Management System developed using Object-Oriented Programming (OOP) concepts. This application allows users to book restaurant tables, place food orders, generate bills, and provide customer feedback through a menu-driven interface.



\---



\## ✨ Features



\- 🪑 Table Booking

\- 🍕 Food Ordering

\- 🧾 Automatic Bill Generation

\- 💬 Customer Feedback

\- ⚠️ Exception Handling

\- 📋 Menu Driven Interface



\---



\## 🛠️ Technologies Used



\- Java

\- Object-Oriented Programming

\- Inheritance

\- Interface

\- Exception Handling

\- Scanner Class
